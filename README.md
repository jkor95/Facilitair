# Meldpunt VWO

Productieversie **v5.8.16** voor `https://meldpuntvwo.nl/`.

## Nieuw in v5.8.16
Het personeels-overzicht voor Facilitair en Conciërge toont nu zonder extra filter direct alle meldingen. De eerdere keuzelijst is verwijderd omdat Safari een oude selectie kon herstellen en daardoor een leeg overzicht kon tonen terwijl er wel meldingen geladen waren.

De beheerder gebruikt nog steeds **Alle meldingen bekijken en openen** om het overzicht zichtbaar te maken. De bestaande bewerkrechten bepalen welke gegevens aangepast mogen worden.
