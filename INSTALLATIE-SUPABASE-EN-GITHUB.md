# Meldpunt VWO v5.7.6 installeren/updaten

## Alleen GitHub aanpassen
Voor v5.7.6 hoef je niets in de database en niets aan `smart-function` te wijzigen.

1. Pak de ZIP uit.
2. Upload/vervang de frontendbestanden in de root van de bestaande GitHub Pages-repository.
3. Wacht tot GitHub Pages de nieuwe versie heeft gepubliceerd.
4. Open daarna de normale website.

Als een apparaat nog een oude versie toont, vernieuw de pagina of open tijdelijk met `?v=5.7.6`.
